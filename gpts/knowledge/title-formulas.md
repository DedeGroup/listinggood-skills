# Amazon Title Formulas Reference — By Category & Marketplace

Proven title templates, keyword patterns, and locale-specific optimization notes.

## Universal Title Formula Components

Every Amazon title should include these elements in priority order:

1. **Brand** (identity + trust signal)
2. **Core product name** (what is it — must match search intent)
3. **Model/SKU/Line** (specificity for repeat buyers)
4. **Primary differentiator** (why this one vs competitors)
5. **Secondary feature/benefit** (additional value)
6. **Use case / audience** (who it's for)
7. **Variation attributes** (size, color, material, count)

## Category-Specific Title Patterns

### Apparel / Fashion
```
Brand + Gender/Age + Item Type + Material/Feature + Occasion/Style + Size + Color
```
Example: `Zara Women's Wool Blend Coat Belted Midi Length Winter Elegant Black M`

Key keywords to include: material (wool/cotton/denim), length (mini/midi/maxi), style (fitted/relaxed/oversized), occasion (casual/formal/work)

### Electronics
```
Brand + Product Name + Key Spec (Screen Size/Capacity/Power) + Compatibility + Color
```
Example: `Anker PowerCore 26800mAh Portable Charger 3-Port PowerIQ USB-C External Battery Pack for iPhone iPad Samsung - Black`

Key keywords: capacity, ports, compatibility list, charging speed

### Home & Kitchen
```
Brand + Product Name + Material/Feature + Size/Dims + Use Case + Set Count
```
Example: `Pyrex Glass Baking Dish Set 6-Piece Oven Safe Borosilicate Glass Bakeware for Cooking Cake Dinner - Clear`

Key keywords: material (glass/stainless/silicone), oven-safe temp, dishwasher-safe, piece count

### Beauty & Personal Care
```
Brand + Product Type + Key Ingredient + Skin/Hair Type + Size + Benefit
```
Example: `CeraVe Moisturizing Cream Daily Face and Body Lotion for Dry Skin with Hyaluramic Acid and Ceramides 19 oz - Fragrance Free`

Key keywords: skin type, key ingredients, size (oz/ml), fragrance-free/paraben-free

### Supplements
```
Brand + Supplement Name + Primary Benefit + Key Ingredient + Dosage + Count + Format
```
Example: `Nature's Bounty Vitamin D3 5000 IU Softgels Immune Support & Bone Health Non-GMO Gluten Free 240 Softgels`

Key keywords: dosage, benefit area, format (softgel/capsule/gummy), count, certifications (non-GMO, gluten-free)

## Marketplace Localization Templates

### US (200 chars) — Default Template
`[Brand] [Product] [Primary Feature] [Secondary Feature] [Use Case] [Size/Color]`

### Germany (200 chars)
`[Marke] [Produkt] [Hauptmerkmal] [Zweck] [Größe/Farbe]`
Notes:
- German compound nouns are powerful SEO tools ("Damen-Winterjacke-Wolle")
- Place primary keyword immediately after brand
- Use "für" (for) to indicate target audience
- Include "Größe" (size) not "Size"

### UK (200 chars)
`[Brand] [Product] [Primary Feature] [Use Case] [Size/Colour]`
Notes:
- British spelling: colour, centre, metre, jewellery, aluminium
- "Pack of" not "Count of"
- Size in cm not inches (or both)

### Japan (250 chars)
`[ブランド名] [商品名] [主な特徴] [用途] [サイズ/カラー]`
Notes:
- Can be longer and more descriptive
- Mix English product names with Japanese descriptors
- Include reading (furigana) for uncommon kanji helps search
- "サイズ" (size), "カラー" (color), "セット" (set/pack)

### France (200 chars)
`[Marque] [Produit] [Caractéristique principale] [Usage] [Taille/Couleur]`
Notes:
- Gendered articles matter for SEO (le/la/un/une)
- Use "pour" (for) to indicate audience
- French grammatical agreement required

### Italy (200 chars)
`[Marchio] [Prodotto] [Caratteristica principale] [Utilizzo] [Taglia/Colore]`
Notes:
- Similar structure to FR
- "Per" (for) for use case
- Gender/number agreement important

### Spain (200 chars)
`[Marca] [Producto] [Característica principal] [Uso] [Talla/Color]`
Notes:
- "Para" (for) for use case
- Similar to IT/FR patterns

## Mobile Optimization Rules

### The 80-Character Rule
On the Amazon mobile app (60%+ of traffic), titles are truncated after approximately **80 characters**.

**The first 80 chars MUST contain:**
1. Brand name (or product name if no brand)
2. What the product IS (core identity)
3. One compelling reason to click (key feature or benefit)

### Mobile Title Testing Framework
Before finalizing, always check:
```
Mobile preview (80 chars): "[first 80 characters of your title]"
✅ Does shopper know what this is? Yes/No
✅ Is there a click reason? Yes/No
✅ Is brand visible? Yes/No/N/A
```

If any answer is "No" → restructure to put critical info earlier.

## A9/A10 Title Ranking Factors (Priority Order)

1. **Keyword presence in first ~50 chars** (highest weight)
2. **Exact match of search query** (phrase match in order)
3. **Keyword proximity** (keywords close together rank higher than scattered)
4. **Title relevance to category** (must match node assignment)
5. **CTR after impression** (title + main image combo drives clicks)
6. **Conversion rate from title-driven sessions**

## Common Title Mistakes & Fixes

| Mistake | Why It Hurts | Fix |
|---------|-------------|-----|
| Brand at end | Wastes prime keyword real estate | Move brand to start |
| All features, no benefits | Doesn't tell customer WHY | Add "for [benefit]" |
| Keyword stuffing | Hard to read, may be penalized | Keep 2-3 KWs max naturally |
| Too short (<80 chars) | Wastes SEO real estate | Add relevant differentiator |
| ALL CAPS words | Looks spammy, lower CTR | Use sentence case |
| "Best seller" etc. | TOS violation risk | Remove superlatives |
| No size/color variant | Misses filter-based search | Add at end |
